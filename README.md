# 🎨 Photo to Real Art

A Python desktop application that transforms ordinary photographs into different artistic styles using OpenCV.

## ✨ Features

- Upload an image
- Choose an art style
- Pencil Sketch
- Cartoon
- Watercolor
- Pop Art
- Oil Painting
- Preview the artwork
- Save the transformed image

## 🛠️ Technologies

- Python
- OpenCV
- Pillow
- Tkinter
